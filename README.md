# Evaluasi IPAS Kelas V — Bab 1: Tumbuhan, Sumber Kehidupan di Bumi

Repositori ini berisi paket lengkap **Soal Evaluasi IPAS Kelas V SD (Kurikulum Merdeka)** untuk **Bab 1: Tumbuhan, Sumber Kehidupan di Bumi**, dilengkapi dengan **Aplikasi Kuis Interaktif berbasis Web** serta dokumen **Naskah Soal, Kisi-Kisi, Kunci Jawaban, dan Rubrik Penskoran**.

## Daftar Berkas

- `index.html`, `style.css`, `script.js` — Aplikasi kuis evaluasi interaktif (dapat langsung dibuka di browser atau dipublikasikan melalui GitHub Pages).
- `soal-evaluasi.md` — Naskah soal evaluasi lengkap siap cetak (20 Pilihan Ganda, 10 Isian Singkat, dan 5 Uraian).
- `kisi-kisi-dan-kunci-jawaban.md` — Kisi-kisi soal berdasarkan Tujuan Pembelajaran, kunci jawaban lengkap, pembahasan singkat, dan pedoman penskoran.

## Cakupan Materi

1. **Topik A: Bagian Tubuh Tumbuhan dan Fungsinya**
   - Akar (tunggang & serabut), batang, daun (tulang daun, klorofil, stomata), bunga, buah, dan biji.
2. **Topik B: Fotosintesis, Proses Paling Penting di Bumi**
   - Bahan dan hasil fotosintesis, peran cahaya matahari dan klorofil, penyimpanan cadangan makanan, serta manfaat fotosintesis bagi kehidupan.
3. **Topik C: Perkembangbiakan Tumbuhan**
   - Bagian-bagian bunga, jenis penyerbukan (sendiri, tetangga, silang, bastar) dan perantaranya, penyebaran biji, serta perkembangbiakan vegetatif alami dan buatan.

## Cara Menggunakan

### 1. Kuis Interaktif (Web / GitHub Pages)
- Buka berkas `index.html` langsung di browser, atau aktifkan **GitHub Pages** pada menu *Settings → Pages* dengan memilih branch `main` dan folder `/ (root)`.
- Siswa dapat mengisi nama dan kelas, memilih mode evaluasi (Semua Topik atau per Topik A/B/C), mengerjakan soal pilihan ganda dengan ilustrasi pendukung, melihat skor akhir, serta membaca pembahasan tiap soal.

### 2. Naskah Cetak untuk Guru
- Gunakan `soal-evaluasi.md` untuk mencetak atau menyalin soal ke lembar kerja siswa.
- Gunakan `kisi-kisi-dan-kunci-jawaban.md` sebagai acuan penilaian dan analisis butir soal.
